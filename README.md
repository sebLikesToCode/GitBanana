## I HATE git. Made an easy-git tool that supports real git too in case of limitations od this one.

## Install

    curl -sL https://raw.githubusercontent.com/sebLikesToCode/GitBanana/main/gitBanana -o ~/.local/bin/gb
    chmod +x ~/.local/bin/gb

If `~/.local/bin` isn't on your PATH, use `/usr/local/bin` with `sudo` instead.

Run `gb --help` to check it worked, or `gb --commands` for everything it does.

**Needs:** bash, git, and [gh](https://cli.github.com) for `publish`.
